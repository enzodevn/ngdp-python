# NGDP API foundation

NGDP V3 begins with a small read-only HTTP boundary. The API reuses the
validated analytical gateway introduced in V2; it does not create a second
data-loading path.

## Current contract

- `GET /health`: process readiness and API contract version.
- `GET /api/v1/energy/summary`: indicators from the active validated snapshot.
- `GET /docs`: interactive OpenAPI documentation generated by FastAPI.

CSV remains the safe default backend. PostgreSQL can be selected through the
existing `NGDP_DATA_BACKEND` environment variable and must pass the same exact
parity gate before its values reach an API response.

## Run locally

From the project root, install the pinned dependencies and start the service:

    python -m pip install -r requirements.txt
    python -m uvicorn src.api.app:app --reload

The local API will be available at `http://127.0.0.1:8000`. Interactive
documentation is available at `http://127.0.0.1:8000/docs`.

## Delivery boundary

This foundation intentionally excludes authentication, write endpoints,
public hosting and direct calls to the Statistics Norway API during requests.
Those capabilities require separate contracts and security decisions.
